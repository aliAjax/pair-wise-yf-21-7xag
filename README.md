# hxyfront-62009 地毯修复纹样档案

手工地毯修复工作室的纹样与修复档案页面：纸本记档电子化，补线色号与实际用线锁死对应。

## 功能

- **地毯档案**：记录产地（波斯 / 安纳托利亚 / 高加索 / 藏毯）、年代、结密度（结/d㎡）、材质、染色类型。
- **纹样标记图**：进入「圈出破损区」模式后，在 SVG 纹样图上逐点点击圈出破损区域，可命名；每个区域可填写修复前、修复后的样子。
- **按区域派色**：每个破损区域挑一个补线色号。
  - 色卡里**库存为 0（已用完）的色号不能派出**：在派色板上点击会被拦下，当场弹出提示要求换一个有余线的色号。
  - 派色即扣一卷备线；未开工前允许撤色退库 / 改色，库存自动回补。
- **开工锁色**：一旦给区域写下工序记录，该区域视为已开工，色号当场锁定，界面置灰且规则层再次拦截，杜绝记录与实际用线错开。
- **工序进度**：按「已补齐色号的破损区域 / 全部破损区域」计算；**全部补齐后才能标成待验收**，否则按钮禁用并提示还差几个区域；验收通过后归档为已验收。
- **按产地筛选**：左侧档案列表按产地过滤，每块地毯带迷你纹样图（破损标记、派色颜色、🔒 开工标记随筛选显示）与补色进度条。
- 数据保存在浏览器 localStorage，可一键重置示例数据。

## 技术栈

React 19 + Vite + TypeScript，纯前端，无外部图片依赖（纹样为内联 SVG）。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62009

```bash
npm run build      # 类型检查通过、产出 dist
npm run preview    # 预览构建产物
```

## 目录

- `src/types.ts` 数据模型
- `src/domain.ts` 派色校验、开工锁定、进度等业务规则
- `src/store.ts` `useArchive` 状态管理（localStorage 持久化、toast 提示）
- `src/data/seed.ts` 示例地毯与色卡
- `src/components/` 纹样图、档案列表、详情/区域编辑、色卡、建档表单
